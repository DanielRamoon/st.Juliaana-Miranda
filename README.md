# st.Juliaana-Miranda

Site institucional e landing page de Juliana Miranda, nail designer e educadora em Juazeiro - BA.

Feito com Next.js (App Router), React, TypeScript e CSS Modules.

## Rodando localmente

Requer Node.js 22 (veja `.nvmrc`).

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Estrutura

- `app/`: layout, página e ícones
- `components/`: layout (Header, Footer, Intro), seções da landing e componentes de UI
- `data/landing.ts`: textos, cursos, serviços e contatos
- `public/assets/img/`: imagens
